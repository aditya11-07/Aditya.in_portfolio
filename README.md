Run Locally
To run this project on your computer:
1. Clone the repository:git clone https://github.com/aditya11-07/aditya-in-portfolio.git
2. Open the project directory:cd aditya-in-portfolio
3. Install dependencies:npm install
4. Start the development server:npm run dev
5. Open the local URL printed in your terminal.
If your GitHub repository has a different name, replace aditya-in-portfolio in the clone URL and directory command with the actual repository name.
